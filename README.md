# Fortune Cookie Wisdom for Developers

One original fortune-cookie line for a software developer, written by a
small deterministic Python program (stdlib only, no network).

Bounty: https://make.fun/bounty/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44

## Run

```sh
python3 main.py
```

This writes the single fortune-cookie line (1–120 characters) to
`/output/entry.txt`, creating `/output` if needed.
